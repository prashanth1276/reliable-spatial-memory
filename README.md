# Spatial Memory Agent

A learning-based embodied AI project exploring spatial memory, scene understanding, and reliable decision-making in dynamic environments.

## Status

🚧 Project under active development.

## Goal

The project serves as a practical bridge from computer science / AI / ML toward robotics, physical AI, and embodied intelligence.

## Research Direction

Reliable Dynamic Spatial Memory for Long-Horizon Embodied Agents

## Core Ideas

- Spatial representation
- Scene understanding
- Spatial memory
- Temporal updates
- Memory consistency
- Embodied decision-making
